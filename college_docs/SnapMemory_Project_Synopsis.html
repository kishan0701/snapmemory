2 Introduction / Background

In social, academic, and professional gatherings—such as weddings, college festivals, convocations, and corporate galas—hundreds of high-resolution photographs and videos are captured. However, distributing these memories back to attendees remains disorganized and frustrating.

Currently, organizers rely on two conventional options:

  • Instant Messaging Groups (e.g., WhatsApp): Enforces severe lossy compression (degrading DSLR photo quality), strips camera EXIF metadata, and exposes personal mobile numbers to large public groups.
  • Cloud Storage Folders (e.g., Google Drive): Involves cumbersome permission requests, lacks an interactive community gallery, and forces attendees to manually browse through over 1,000 photos just to find the 3 or 4 pictures they appear in.

SnapMemory is a modern, zero-install web application that provides centralized, high-fidelity media management. Guests scan a table QR code to view and contribute lossless photos, and use an integrated Client-Side AI Face Recognition engine to retrieve all their pictures in under 2 seconds by uploading a single selfie.

3 Problem Statement and Motivation
Problem Statement: There is no unified, zero-install, privacy-first web application that allows event organizers to collect uncompressed event photos while enabling guests to instantly find their personal photos without installing heavy mobile apps or exposing biometric data to cloud servers.

Motivation:

  • Zero App Friction: Guests do not want to download a native mobile app from Play Store for a 1-day event. SnapMemory loads instantly on any mobile browser.
  • Lossless Quality: Preserves original camera resolution, aspect ratio, and timestamps without compression artifacts.
  • Biometric Privacy via Edge AI: Uploading facial biometric scans to third-party servers presents severe privacy and regulatory risks. SnapMemory executes neural network inference locally within the user's browser; no biometric data ever leaves the device.
  • Host Governance: Event hosts retain full moderation privileges through contributor approval pipelines and real-time event telemetry.
4 Objectives and Scope

Objectives:

  • Develop an intuitive web application where organizers create and manage customized event media hubs.
  • Generate automatic, high-resolution vector QR codes for instant physical and digital attendee onboarding.
  • Implement a client-side AI face recognition engine (128-dimensional embedding vectors & Euclidean distance) for instant photo retrieval.
  • Build a responsive Masonry/Grid gallery with fullscreen Lightbox inspection and video player.
  • Create a multi-file drag-and-drop upload zone with progress indicators and client-side format validation.
  • Provide an administrative dashboard for contributor moderation, album management, and storage telemetry.
  • Enable batch image downloads and client-side ZIP packaging via JSZip.

Scope (Included):

  • Dynamic event creation wizard with custom branding, dates, and privacy tiers (Public / Password / Invite-Only).
  • Vector QR code generator with one-click download/print for event signage.
  • Client-Side AI "Find My Photos" selfie scanner with similarity percentage ranking.
  • Contributor Approval Queue (Pending, Approved, Rejected workflows).
  • Real-time telemetry dashboard (visitors, photo counts, downloads, storage metrics).
  • Multi-user authentication (Email/Password with 4-level strength meter + simulated OAuth).
  • Download Center supporting selective batch and complete ZIP archive generation.

Out of Scope (Future Work):

  • Native Android/iOS mobile application publishing.
  • Real-time automated face tracking inside long-duration 4K video files.
  • Integrated commercial payment gateway (e.g. Razorpay) for professional photo monetization.
5 System Architecture

SnapMemory is engineered as a modern Three-Tier Client-Cloud Reactive Architecture:

1. Presentation Tier

React 18 & TypeScript: Component-based UI with strict type safety.
Tailwind CSS: Dark glassmorphic aesthetic.
Lucide Icons & Framer Motion: UI animations.
HTML5 Canvas API: Edge AI face vector extraction.

2. Application Tier

Vite 8 Runtime & Router v7: Fast routing & bundling.
Service Layer: Abstracted REST & Supabase client.
Resilient Dual-Mode: Auto-fallbacks to local storage if offline.
JSZip: In-browser ZIP bundling.

3. Data Tier

Supabase PostgreSQL 15: Relational tables (users, events, albums, media, contributors, analytics).
Supabase Storage: High-resolution asset buckets with CDN caching.

Execution Flow: Guest Scans QR Code → React loads Event Route (/e/:slug) → Service Layer fetches Media & Albums → Guest uploads Selfie in "Find My Photos" → Browser extracts 128-D Face Embeddings locally → Euclidean distance match filters event photos → Matched photos displayed with % similarity in < 2s

User Roles: Host/Admin (full governance & analytics), Approved Contributor (upload privileges), Guest Attendee (view, face search, and download).

Security Layer: Edge biometric isolation, Role-Based Access Control (RBAC), client-side entropy password meters, and sanitized SQL/XSS parameters.
