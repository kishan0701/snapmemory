📌 PROJECT KYA HAI?
--------------------
Socho ek app jahan wedding ya birthday ya college fest ke baad
saare log apne photos ek jagah upload kar sakte hain.
Koi WhatsApp group nahi, koi USB nahi — bas ek link ya QR code
scan karo aur sabke photos ek saath dikh jaate hain.

Naam: EventSnap
Bana raha hoon: React (website banana ka tool) + Supabase (database)

[ 1 ] HOME PAGE  (/)
      Pehli baar kholo toh yeh dikhta hai. Bada hero section,
      features list, occasions (Wedding/Birthday/College), 
      "How it works" aur sign up CTA.

[ 2 ] AUTH PAGE — LOGIN + SIGNUP  (/login, /signup) ✨HD SLIDING CARD
      DONO ek hi page pe! Ek ultra-premium animated card hai:
      - Sliding panel mein cinematic HD event celebration photo locally
        installed hai (/public/images/auth-cover.jpg)
      - "Create Account" ya "Sign In" click karne pe image panel smoothly
        left se right slide hoti hai (Zero overlap bug, pixel perfect!)
      - Demo login: Niche subtle small text me kishan@example.com (with 1-click Auto-fill)
      - Google OAuth button + full validation + password eye toggle

[ 3 ] FORGOT PASSWORD  (/forgot-password)
      Email daalo, link milega password reset ke liye.

[ 4 ] DASHBOARD  (/dashboard) — LOGIN REQUIRED
      Tumhare saare events ek jagah. Stats: total photos,
      events, views, contributors. Search + filter + sort bhi.

[ 5 ] CREATE EVENT  (/create-event) — LOGIN REQUIRED
      3-step wizard:
      Step 1 → Event ka naam, type, date, location
      Step 2 → Privacy (public/private/password)
      Step 3 → Collaboration settings

[ 6 ] EVENT GALLERY  (/event/:id)
      5 tabs:
      → Gallery  : Photos masonry/grid layout mein
      → Albums   : Albums ke cards
      → Upload   : Drag & drop upload
      → People   : Kiski kiski photos hain
      → Analytics: Kitne views, downloads, charts

[ 7 ] EVENT SETTINGS  (/event/:id/settings) — OWNER ONLY ✨NEW
      4 tabs — General, Privacy, Sharing, Danger Zone
      Danger zone mein event delete ka option bhi hai
      (type karo event ka naam confirm karne ke liye)

[ 8 ] DOWNLOAD CENTER  (/event/:id/downloads) ✨NEW
      Photos select karo checkboxes se, album se filter karo,
      sab ek saath download karo. Mobile pe sticky bar bhi hai.

[ 9 ] FIND MY PHOTOS  (/event/:id/find-my-photos)
      Selfie upload karo → AI face matching → tumhare saare
      photos mil jaate hain event mein with confidence %

[ 10 ] 404 PAGE  (koi bhi galat URL)
       Branded not-found page, wapas jaane ka button.

====================================================================
  COMPONENTS — REUSABLE PARTS (LEGO BLOCKS)
====================================================================

🧭 NAVBAR
   Transparent hai landing page pe, baaki pages pe glass effect.
   Login nahi kiya → Login/Signup button dikhta hai.
   Login kiya → Avatar, naam, aur dropdown menu (logout etc).
   Mobile pe hamburger menu bhi hai.

📷 MEDIA GRID
   Photos dikhane ka main component.
   Toggle karo Pinterest-style masonry ya square grid mein.
   Search, filter (album/type), aur sort bhi kar sakte ho.
   Photo pe click → Lightbox khulta hai.

🔍 LIGHTBOX
   Full screen mein photo dekhne ke liye.
   Left-Right arrow ya keyboard se navigate karo.
   Zoom in/out, like, share, download.
   Info panel slide karke aata hai — size, dimensions, upload date.
   Neeche thumbnail strip hai sab photos ki.

🎥 VIDEO PLAYER ✨NEW
   Custom video player. Play/pause, progress bar (click to seek),
   mute, fullscreen. Controls 2.5 second baad chhup jaate hain.

📋 UPLOAD QUEUE ✨NEW
   Upload hone wali files ki list.
   Har file ka progress bar, status (waiting/uploading/done/failed).
   Failed? Retry button. Done? Remove button.

📱 QR SHARE PANEL
   Event ka QR code generate karta hai.
   Download PNG mein. Copy link bhi.

🤝 CONTRIBUTOR REQUEST MODAL
   Guests ke liye — upload access maangne ka popup.
   Message likh ke bhejo organizer ko.
